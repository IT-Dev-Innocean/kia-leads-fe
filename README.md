# KIA Leads Form

Leads Form KIA Indonesia

## Features

- [x] Form validation
- [x] Form submission
- [x] Form success state
- [x] Form error state
- [x] Form loading state
- [x] Form submission success state
- [x] Form submission error state
- [x] Form submission loading state

## Tech Stack

- [x] React
- [x] Tailwind CSS
- [x] TypeScript
- [x] Vite
- [x] React Router
- [x] React Query
- [x] React Hook Form
- [x] React Hook Form

npm run dev
